# Midnight agent pilot

**Work in progress.** Findings will go at the top of this page once the scorecard runs are complete.

An independent, one-week pilot asking: how well do AI coding agents build on Midnight, and how much does Midnight's own AI tooling (Kapa MCP, Midnight Expert) change that?

- `contract/`: a privacy-preserving consent attestation contract in Compact (demo only, no real data)
- `evals/`: tasks, hidden tests, the scripted harness, and results
- `FRICTION_LOG.md`: every snag, with repro steps
- `NEXT_STEPS.md`: recommendations, grounded in the data

Not affiliated with Midnight Foundation.
